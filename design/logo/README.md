# Novora – Logo (PNG)

Aktuelle Marke: **Novora**. Ordner `novora/` enthält den kompletten PNG-Satz.

| Datei | Größe | Verwendung |
|---|---|---|
| `novora-icon.png` | 1024 × 1024 | Master, Stores, Präsentationen |
| `novora-512.png` | 512 | PWA, Play Store |
| `novora-192.png` | 192 | Android, Favicon |
| `novora-180.png` | 180 | Apple Touch Icon |
| `novora-96/64/48/32.png` | div. | Tray, kleine Icons, Favicon |
| `novora-wordmark.png` | 1400 × 420 | helle Schrift, für dunkle Flächen |
| `novora-wordmark-dark.png` | 1400 × 420 | dunkle Schrift, für helle Flächen |

**Marke:** dunkles, abgerundetes Quadrat, Rand im Cyan-Violett-Verlauf, Monogramm „N“ aus zwei hellen Tasten und einem diagonalen Farbverlauf.

**Farben:** Hintergrund `#06090D`, Tasten `#E9EEF5`, Cyan `#22D3EE`, Violett `#A78BFA`.

**Regeln:** Schutzzone = halbe Monogrammhöhe, Mindestgröße 16 px, Wortmarke nicht unter 24 px Höhe. Keine fremden Marken- oder Produktzeichen verwenden.

**Hinweis:** Name ist markenrechtlich nicht geprüft. Novora Group, novora.co, novora.live und weitere existieren; DPMA/EUIPO-Recherche Kl. 9/42 vor Release.

`legacy/` = alter Satz, nur als Archiv.
